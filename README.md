CEPO splits the prompts of a multi-agent system into a shared **coordinator prompt** (system-level
coordination) and per-agent **executor prompts** (agent-level execution), and optimizes the two
layers sequentially with role-aligned guidance on top of an existing prompt optimizer
(PE2, OPRO, ProTeGi, ...).
